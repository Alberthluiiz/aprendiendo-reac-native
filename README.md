# Aprendiendo React Native

Mis proyectos para aprender a crear apps móviles para **Android e iOS** con React Native y Expo.
Cada proyecto vive en su propia carpeta y tiene su propio README con instrucciones.

| Carpeta | Proyecto | Estado |
| --- | --- | --- |
| [`ritmo-musica/`](./ritmo-musica) | **Ritmo**: app de música con diseño propio, inspirada en Spotify | Paso 1 de 8 |

## Requisitos generales

- [Node.js](https://nodejs.org/) 20 o superior
- La app **Expo Go** en tu teléfono ([Android](https://play.google.com/store/apps/details?id=host.exp.exponent) / [iOS](https://apps.apple.com/app/expo-go/id982107779))
- Un editor de código (recomendado: VS Code)
